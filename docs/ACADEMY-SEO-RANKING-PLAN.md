## Authority outreach targets

Prioritize relevant, editorially earned mentions rather than generic directory submissions:

1. Official training and partner course pages.
2. Trainer LinkedIn articles that link to the appropriate Academy landing page.
3. Participating employer or learner case studies, with permission.
4. Singapore SME and professional-community event or resource pages.
5. Workshop recaps containing original photos, outcomes and a contextual course link.

## Measurement rules

- Use the Search Console query and page dimensions together.
- Filter to Singapore and compare rolling 28-day periods.
- Track impressions, average position, clicks and CTR for each exact query.
- Avoid reacting to daily volatility; review at 14 and 28 days after Google recrawls the pages.
- If position improves but CTR remains weak, test the title and description without changing the page’s keyword assignment.
